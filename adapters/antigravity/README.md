# Adaptador Google Antigravity

Configure o espaço de trabalho na raiz do repositório ou aponte a conversa para
`skills/legal-process-parser/`. O arquivo `.mcp.json` na raiz expõe o servidor
local `auditor-processual` via stdio (`scripts/mcp_server.py`) com ingestão,
busca paginada, catálogos de pretensões e peças, cálculos forenses,
pseudonimização LGPD e exportação `.docx`.

Leia `AI_ENTRYPOINT.md` primeiro e carregue apenas a tarefa e os gatilhos de
`routing/task-router.json`, sem abrir instruções de outras plataformas.
