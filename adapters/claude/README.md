# Adaptador Claude

Use um pacote com `SKILL.md` na raiz, como `auditor-processual-claude.zip`, ou
aponte a conversa para `skills/legal-process-parser/`. Leia `AI_ENTRYPOINT.md`
primeiro quando o acesso for por GitHub e carregue somente a tarefa necessária.

A análise de um processo inteiro percorre todos os documentos e imagens do
corpus, sem exigir a leitura das instruções de outras plataformas. A redação
jurídica usa `analise_juridica.md`, fatos e fontes diretas, e pesquisa normativa
oficial ampla antes de concluir.
