# Adaptador Grok

Grok não usa o formato `SKILL.md` como plugin universal. Use
`SYSTEM_INSTRUCTIONS.md` como instrução do projeto ou da conversa e anexe o
processo, `processo_estruturado.md`, `relatorio_processual.md` e os índices
necessários.

Não envie o repositório inteiro como um único contexto. Anexe o corpus do caso e
consulte os arquivos por busca documental. Para arquivos sigilosos, prefira
upload privado e remova-os ao terminar conforme a política da conta. Em
análise, utilize `legal_narrative.json`/`analise_juridica.md` e vincule a tese a
fontes internas e legislação oficial conferida.
