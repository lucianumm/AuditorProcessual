# Adaptador Grok

Este adaptador fornece `SYSTEM_INSTRUCTIONS.md` como instrução do projeto ou
da conversa, sem presumir instalação nativa de plugin pela plataforma. Anexe
o processo e leia o núcleo `SKILL.md`, o roteador e somente as referências da
tarefa. Use os Markdown cumulativos e os índices disponíveis para navegação.

Não envie o repositório inteiro como um único contexto. Busca documental
localiza trechos, mas não substitui a leitura integral das páginas e visuais
relevantes na primeira análise completa. Para arquivos sigilosos, confira
permissões e retenção da conta antes do upload. Preserve originais, versões e
Markdown cumulativos; não exclua anexos automaticamente. Alterações de retenção
ou exclusão dependem da instrução do usuário e da política aplicável.

Em análise, siga a revisão v4 e vincule fatos, provas, normas, teses e pedidos
a fontes verificadas. Uma lacuna deve ficar delimitada, sem bloquear questões
independentes. Toda minuta exige revisão profissional antes de protocolo.
